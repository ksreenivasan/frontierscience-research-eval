# FrontierScience-Research 9-question pilot — 2026-08-25

**Directional bounded pilot; not comparable to the official 30-trial-per-question protocol.**

## Condition

- Pinned public Research gold set revision `25ed67db7da8f4591484e764008ff585544f5a30`.
- Predeclared deterministic subset: **9/60 questions**, three each from physics, chemistry, and biology and one per low/medium/high length stratum.
- Four requested model lanes, **one authoritative answer per model/question**: 36 answer cells and 36 judgments.
- Direct single-turn prompt; no tools, browsing, search, files, code execution, or agent loop.
- Uniform 32,768-token output cap and high reasoning/thinking for every model. Qwen used the pinned Alibaba OpenRouter endpoint with routing fallbacks disabled; no fallback model was used.
- Judge: `gpt-5-2025-08-07`, high reasoning, published Research rubric prompt; one answer passes at `>=7/10`.

## Completion and audit

- Denominators are exactly 9 per model and 3 per subject/model; all 36 unique answer cells have one authoritative judgment.
- Claude produced two provider refusals and exhausted the output cap twice: one capped response retained a visible partial answer, while one spent all 32,768 output tokens on thinking and produced no visible answer. These were retained as model outcomes and scored against the same rubric; no answer trial was repeated.
- One Qwen response arrived as malformed JSON and was retried once as a transport retry. The authoritative Qwen answer still uses the requested model and Alibaba endpoint; this did not add a second scored trial.
- A representative audit covered the shared chemistry pass task across all four models, GPT's 10/10 biology result, one Claude refusal, and the empty capped Claude result. The judge explanations applied the supplied rubric coherently and matched stored totals and binary thresholds.
- Aggregate invariants passed: 9 tasks with 3/subject, 9 cells/model, unique model-task keys, matching answer/judgment IDs, parseable scores in `[0,10]`, high reasoning recorded for every lane and judge, and no tool-enabled payloads.
